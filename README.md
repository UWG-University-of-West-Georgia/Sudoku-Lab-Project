# Sudoku Game App

### Objective
The Sudoku game app is a classic puzzle that involves placing numbers in a 9x9 grid. The system presents a partially filled grid, and the objective is to place the numbers 1 through 9 in the remaining empty cells, ensuring that each number appears only once in each row, each column, and each of the nine 3x3 subgrids.

### Rationale
The rationale behind this project stems from my personal interest in logic puzzles.
